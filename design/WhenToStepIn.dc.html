The one decision you make

When to step in

Almost everything is “Change this…”. Switching the whole brand to Manual is rare — and it stops the agents working for you.

One post is wrong → “Change this…”

Stay on Auto. Say what should be different in plain words. That single post is redone; everything else keeps running.

Notes that work well
“Lead with the price, not the amenities.”
“Too much text on the image — cut it to one line.”
“Use a daytime shot, not blue hour.”

It keeps happening → set a rule

If you have given the same note twice, it belongs in Memory as a rule. Rules are never broken, so the note stops being your problem.

A campaign you must control → Manual

A launch, a legal-sensitive announcement, a one-off you need to write yourself. Switch the brand to Manual, do the work, then switch back. While it is Manual, nothing is produced for you.

Every note you give is kept against the brand, so the system gets more right the longer you use it. You can read, edit or delete any of it under Settings → 🧠 Memory.
