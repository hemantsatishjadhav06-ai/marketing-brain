# Marketing Brain — Console UI/UX (design canvas)

A Gen-Z-premium, dark-first design of the Marketing Brain operator console, drawn
from the Master Figma UI/UX Design Specification. Organised around the
KNOW→THINK→CREATE→LAUNCH→CONVERT→MEASURE→LEARN loop — "hide complexity, expose control".

## Screens (each an artboard)
- `Main.dc.html` — Command Center (health score, AI opportunities, today's AI work)
- `AskBrain.dc.html` — natural-language command surface → Mission
- `CreativeStudio.dc.html` — left controls / centre 4:5 canvas / right "Brain used" intelligence
- `ApprovalCenter.dc.html` — human-in-the-loop decisions incl. a high-impact ad-spend gate
- `DesignSystem.dc.html` — palette, type (Space Grotesk + Manrope), components, execution modes

`canvas.json` lays the artboards out on one pan/zoom canvas.
`marketing-brain-console-uiux.html` is the self-contained, publishable canvas
(open in a browser to view / export PNG·PDF).

Published canvas: https://claude.ai/code/artifact/6009f9ea-c037-4f74-9ad1-f3996344e9f8

These artboards mirror the palette and structure of the live console at
`/operator.html`, so the shipped product and this design read as one system.
